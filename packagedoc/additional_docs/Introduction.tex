\section{Introduction}

\textbf{MicroserviceBase} is a Python framework for building, managing, and orchestrating
microservices with RabbitMQ-based communication.

It provides:

\begin{itemize}
   \item \textbf{Microservice Framework}: Base classes for creating services with RPC and pub/sub patterns
   \item \textbf{Service Registry}: Dynamic service registration and discovery via RabbitMQ exchange
   \item \textbf{FastAPI Bridge}: REST API and WebSocket gateway connecting GUI to microservices
   \item \textbf{Manager GUI}: Electron and browser-based dashboard for monitoring and controlling services
   \item \textbf{Local Process Hub}: Process lifecycle management with graceful shutdown
   \item \textbf{Hexagonal Architecture}: Clean separation via ports and adapters pattern
\end{itemize}

\subsection{Target Audience}

This package is designed for developers who need to:

\begin{itemize}
   \item Build microservices that communicate via RabbitMQ message broker
   \item Monitor and manage services through a graphical dashboard
   \item Manage local service processes with start, stop, and import capabilities
   \item Deploy a standalone desktop application for service management
\end{itemize}

\subsection{Prerequisites}

\begin{itemize}
   \item Python 3.10 or higher
   \item RabbitMQ server (message broker)
   \item pika package (RabbitMQ client for Python)
   \item FastAPI and uvicorn (for the bridge)
   \item Node.js and npm (for GUI development)
\end{itemize}
