Reading paths

For a new contributor: README.md (root) → architecture.html → runtime_model.html → walk an example (examples/PowerDeviceService/README.md) while the Manager GUI runs in another window.

For someone migrating a downstream fork: changelog.html first, then _legacy/CONCEPT.md ↔ concepts.html side-by-side to map old terms onto new.

For an operator who just needs to run things: MicroserviceManagerGUI/README.html → ops_consul_nomad.html (the GUI-driven path replaces all CLI ops).
