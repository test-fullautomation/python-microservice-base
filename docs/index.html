Reading paths

For a new contributor: Repo README → architecture → runtime_model → walk an example (examples/PowerDeviceService/) while the Manager GUI runs in another window.

For someone migrating a downstream fork: changelog first, then _legacy/CONCEPT.md ↔ concepts side-by-side to map old terms onto new.

For an operator who just needs to run things: MicroserviceManagerGUI/README → ops_consul_nomad (the GUI-driven path replaces all CLI ops).
