Getting Started

Microservice Manager is a graphical interface for managing, monitoring, and interacting with microservices running on a RabbitMQ message broker. It provides real-time service status, an API explorer, code helpers, fleet management, and a service creation wizard.

Dual Hosting

The GUI runs in two modes:

  • Electron — standalone desktop app with native features (settings file, Python bridge auto-launch)
  • Browser — served by the FastAPI bridge at http://localhost:1112/gui; no installation required

Both modes share the same web front-end and connect to the same FastAPI bridge.

Three Modes

Use the mode toggle buttons in the top navigation bar to switch between:

  • Services — browse connected services, call APIs, view code helpers
  • Service Network — fleet dashboard and local hub management
  • Service Creator — step-by-step wizard to scaffold a new microservice

Connecting to Broker

Click the Connect button in the top-right corner to open the login dialog.

Connection Fields

  • Broker URL — the RabbitMQ host and port (e.g. localhost:5672)
  • Routing Key — the routing key used by the Registry Service (e.g. ServiceRegistry)
  • Fleet API URL (Advanced) — optional URL for the Fleet Web API, used by the Service Network tab

Multi-Broker

You can connect to multiple brokers simultaneously. Each connection appears as a chip in the navbar. Services from all brokers are merged into the sidebar, grouped under collapsible broker headers.

Tip
Click a broker chip to focus on its services. Click the button on a chip to disconnect from that broker.

Disconnect

Click the Disconnect button (the Connect button changes label once connected) to close all broker connections and clear the service list.

Services Mode

The default mode. The sidebar lists all registered services. Click a service to view its GUI panel in the content area.

Sidebar Navigation

  • Use the search bar at the top to filter services by name
  • Services show a status icon — green for ready, red for not ready
  • When connected to multiple brokers, services are grouped under collapsible broker headers

Service GUI Plugins

Each service can provide a custom GUI plugin (HTML + JS) loaded from web/services/<ServiceName>/. The plugin is loaded once and cached for fast switching between services.

API Explorer

Click the icon next to a service name in the sidebar to open the API Explorer. This lets you:

  • Browse the service's registered API endpoints
  • Send test requests with custom JSON payloads
  • View responses in real time

Code Helper

Click the icon to open the Code Helper modal. It generates ready-to-use code snippets for calling the service from Python, JavaScript, or Robot Framework.

Service Network

Switch to Service Network mode to manage distributed service infrastructure. This mode has two sub-tabs:

Fleet Dashboard

Provides an overview of all hub nodes in your fleet:

  • View online/offline status of each hub
  • Monitor service counts and health across the fleet
  • Requires a Fleet API URL (configured in the login dialog or Settings)
Note
The Fleet dashboard polls the Fleet Web API periodically. If no Fleet API URL is configured, the dashboard will show a setup prompt.

Local Hub

Manage processes on the local machine:

  • Start, stop, and restart service processes
  • View process logs and status
  • Import or add new service entries
  • Configure process entries in hub_processes.json

Service Creator

The Service Creator wizard guides you through scaffolding a new microservice. Switch to Creator mode using the top navigation bar.

Wizard Steps

  1. Basic Info — service name, version, description, group, routing key, transport type
  2. API Methods — define request/response endpoints
  3. GUI Support — optional GUI plugin configuration
  4. Review & Generate — preview and download the scaffolded project
Tip
The left sidebar shows your progress through the wizard steps. You can click any completed step to go back and modify it.

Settings

Click the gear icon in the navbar to open the Settings dialog.

Available Settings

  • Python Path — path to the Python interpreter (used by Electron to spawn the FastAPI bridge)
  • Broker Host / Port — default broker connection values
  • Bridge Port — port for the FastAPI bridge (default: 1112)

Storage

  • Electron mode — settings saved to a JSON file on disk
  • Browser mode — settings saved to sessionStorage (cleared when tab closes)

Troubleshooting

Cannot connect to broker

Check these first
  • Verify the RabbitMQ server is running on the specified host and port
  • Ensure the FastAPI bridge is running (http://localhost:1112/docs should show the Swagger UI)
  • Check that no firewall is blocking the connection

Services not appearing

  • Confirm the Routing Key matches your Registry Service configuration
  • Check the browser console (F12) for error messages
  • Try disconnecting and reconnecting

Service GUI not loading

  • The GUI plugin must exist at web/services/<ServiceName>/
  • Check the browser console for JavaScript errors in the plugin
  • Ensure the plugin's JS file uses the window.MicroserviceManager namespace

Fleet dashboard shows "No Fleet API configured"

  • Set the Fleet API URL in the login dialog (Advanced Settings) or in Settings
  • Ensure the Fleet Web API service is running and reachable

Bridge not starting (Electron)

  • Verify the Python Path in Settings points to a valid Python interpreter
  • Ensure MicroserviceBase is installed in that Python environment (pip install MicroserviceBase)
  • Check the Electron dev tools console for bridge startup errors
